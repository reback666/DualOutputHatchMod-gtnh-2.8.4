# 输出总成 (ME) · Dual Output Hatch (ME)

一个 GTNH（GregTech: New Horizons）附属 mod，添加了一个**同时具备输出总线(ME)与输出仓(ME)功能的舱室**：多方块的物品与流体产出直接进入 ME 网络，一个格子顶两个。

## 特性

- **二合一输出**：同时被多方块识别为输出总线（物品）与输出仓（流体），省一个舱位。
- **无限缓存**：物品与流体缓存均为 long 级上限，产出先入缓存，再自动冲入 ME 网络。
- **冲入间隔可调**：GUI 内 1–72000 tick 自由调整（默认 10）。
- **输出优先级**：同一多方块放多个输出总成时，物品与流体优先进优先级高的。
- **双模式过滤**：
    - **标签过滤**——按 OreDictionary 词典名匹配物品、按流体注册名匹配流体（逗号分隔多个）；
    - **具体过滤**——幻影格标记具体物品与流体（18+18 格），像库存二合一输入仓(ME)一样点格子即可；
    - 两种模式的标记独立保存，随时切换；标记全空 = 接受全部。
- **原生 NEI 交互**：缓存列表与过滤标记格支持悬停查看信息、`R` 查配方、`U` 查用途、`A` 收藏（流体经 GT 流体显示栈查询）。
- **兼容性**：对 GT 本体、GT++、TecTech、TST 等自建归类路径的多方块均生效；与库存二合一输入仓(ME)等 mod 和平共存。

|---|---|

耗时 300 ticks / 30 EU/t。

## 使用说明

1. 像普通输出仓一样放入多方块结构，**软锤右击机器重新成型**即可被识别；
2. 右击舱室打开 GUI：
    - **缓存视图**：实时显示已缓存的物品与流体（最多 400 种），悬停查看详情，支持 NEI 快捷键；
    - **设置页**（左上角第二个页签）：调整冲入间隔、输出优先级、过滤模式与过滤内容；
3. 用线剪右击舱室可更改 ME 连接行为（与原版 ME 仓一致）。

### 输出顺序

舱室的分发顺序为：**高优先级输出总成 → 低优先级输出总成 → 普通输出总线/输出仓**。同优先级时按结构内摆放顺序取第一个。被过滤拒绝的物品/流体不会消失，会转给其它输出舱；全部拒收时留在机器内（机器可能因此停轮，属预期行为）。

## 构建

在 GTNH 标准开发环境下（JDK 17/21/25 均可）：

```bash
./gradlew build
```

产物在 `build/libs/`。版本号可通过环境变量覆盖：`VERSION=1.0.0 ./gradlew build`。
